Privacy — Find in Commit History

A JetBrains plugin that searches your local Git history for a string (the git log -S and git log -G search, also called "pickaxe"). This notice says exactly what it reads, what it keeps, and what leaves your machine. The short answer: nothing leaves your machine.

What the plugin is

  • A free JetBrains plugin, Find in Commit History, plugin id com.tgglabs.pickaxe, MIT licence.
  • It searches the Git history of the project you have open, and shows the commits where a string was added or removed.
  • Open source: the source of every line is public, so the behaviour described below can be read directly, not on trust: github.com/tgg49099-dotcom/find-in-commit-history.

What it reads

  • Only the Git repository of the project you have open: the objects, trees and commits of the local .git directory, read through the Eclipse JGit library, exactly as the git command line does.
  • Only the files and commits that the search itself touches — for example, the blobs of the files changed by each commit, compared one after the other.
  • It never reads the files of your project as they are on disk, only their historical versions stored in Git.

What it stores

  • Nothing. The plugin writes no file, no history of your searches, no index, no cache, no identifier, no account.
  • Your IDE may of course keep its own cache of the plugin inside its own configuration directory. That is the IDE's behaviour, not the plugin's, and it contains nothing about your searches.

What leaves your machine

  • Nothing. The plugin contains no network code: it has no HTTP client, no telemetry, no update check, no licence server, no crash-reporting service.
  • No data is sent to us, to JetBrains, or to any third party. The search is performed entirely on your machine, with your repository.
  • Your IDE itself may have its own telemetry settings; those belong to JetBrains and are configured in the IDE, not by this plugin.

Third parties

  • None. No analytics, no advertising, no attribution service, no external host.
  • One open-source library is bundled inside the plugin and runs entirely locally: Eclipse JGit (Eclipse Distribution License v1.0 / BSD-3-Clause) and JavaEWAH (same family of licences). They are not contacted over the network.
