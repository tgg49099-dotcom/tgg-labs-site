Publishing “Find in Commit History” on the JetBrains Marketplace

Everything to fill in, field by field, for the first publication of the plugin (version 0.0.1). One gesture, about five minutes, no cost.

Read this first

  • JetBrains' own documentation: “The first plugin publication must always be uploaded manually”. After this version, the later ones go through the API.
  • Do not use the “Upload plugin” button of the vendor page (plugins.jetbrains.com/vendor/tgg-labs): on that page the button adds a version to an existing plugin, and our existing plugin is ML Experiment Cockpit (id 35416) — it would overwrite it. Use the account-menu path below.

The path

  1. Open plugins.jetbrains.com and log in.
  2. Top-right account menu (avatar) → “Upload plugin”.
  3. Select the vendor Tgg Labs (tgg-labs).
  4. On the form, choose “Create new plugin” if that option appears.
  5. Fill in the fields below, then upload the attached ZIP as version 0.0.1.
  6. Save, then send me the plugin URL (it contains the numeric plugin id).

Description to paste (HTML)

<p>Search your <b>Git history</b> for the commits that add or remove a string — the
<code>git log -S</code> and <code>git log -G</code> ("pickaxe") search, inside your IDE.</p>
<ul>
<li><b>Find where a string came from</b> — type a string, get the list of commits that added or removed it, most recent first.</li>
<li><b>No false positives</b> — a line rewritten identically is not reported: only a real change in the number of occurrences is.</li>
<li><b>Regular expressions</b> — match the diff itself with <code>git log -G</code> semantics.</li>
<li><b>Filter by path</b> — restrict the search to the files you care about. Binary files are ignored.</li>
<li><b>Works with your own repository</b> — the history is read locally, nothing is sent anywhere.</li>
</ul>

If the field refuses HTML, paste this plain text

Search your Git history for the commits that add or remove a string — the git log -S and git log -G
("pickaxe") search, inside your IDE.
- Find where a string came from — type a string, get the list of commits that added or removed it, most recent first.
- No false positives — a line rewritten identically is not reported: only a real change in the number of occurrences is.
- Regular expressions — match the diff itself with git log -G semantics.
- Filter by path — restrict the search to the files you care about. Binary files are ignored.
- Works with your own repository — the history is read locally, nothing is sent anywhere.
